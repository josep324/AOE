# Safata d'entrada de models

Deixa aquí els models **tal com els has descarregat**, amb qualsevol nom i format:
`.zip`, `.glb`, `.gltf`, `.fbx`, `.obj`, amb les seves textures.

Aquesta carpeta **no** entra al joc. Claude revisa cada fitxer, el converteix a `.glb`,
l'optimitza (mida i textures), li posa el nom que toca i el mou a `assets/models/`.

Per a cada model, indica (al missatge del commit o al xat):
- què és (p. ex. «caserna», «arbre», «mina d'or», «arquer»)
- d'on l'has tret (enllaç) i la llicència (CC0, CC-BY…), per als crèdits
